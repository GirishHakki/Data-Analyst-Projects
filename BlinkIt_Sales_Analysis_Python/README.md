# 🛒 Blinkit Sales Analysis using Python

## 📌 Project Overview
This project focuses on analyzing **Blinkit’s sales performance, customer ratings, and outlet characteristics** using **Python (Jupyter Notebook)**.  
The objective is to extract meaningful business insights from the dataset and present them using **KPIs and visualizations**.

This is a **beginner–friendly Data Analyst project** demonstrating skills in data cleaning, exploratory data analysis (EDA), and data visualization.

---

## 🎯 Business Objective
To conduct a comprehensive analysis of:
- **Sales performance**
- **Customer satisfaction**
- **Inventory and outlet distribution**

The insights help identify:
- High-performing product categories
- Sales patterns based on fat content
- Outlet-wise performance
- Location and size impact on revenue

---

## 📊 Key Performance Indicators (KPIs)
The following KPIs were calculated and analyzed:

- **Total Sales** – Overall revenue generated
- **Average Sales** – Average revenue per sale
- **Number of Items Sold** – Total items sold
- **Average Rating** – Customer satisfaction score

---

## 📈 Visual Analysis & Insights
The project includes the following visualizations:

1. **Total Sales by Fat Content**  
   - Analyzes how low-fat vs regular items contribute to revenue  
   - Visualization: Donut Chart

2. **Total Sales by Item Type**  
   - Identifies top-performing product categories  
   - Visualization: Bar Chart

3. **Fat Content by Outlet (Total Sales)**  
   - Compares outlet performance segmented by fat content  
   - Visualization: Stacked Column Chart

4. **Total Sales by Outlet Establishment Year**  
   - Evaluates how outlet age impacts sales  
   - Visualization: Line Chart

5. **Sales by Outlet Size**  
   - Analyzes the relationship between outlet size and revenue  
   - Visualization: Pie / Donut Chart

6. **Sales by Outlet Location**  
   - Assesses sales distribution across locations  
   - Visualization: Funnel Map / Category Plot
